# PlaylistPro 최종 발표 콘셉트

## 발표의 커뮤니케이션 목표

발표가 끝났을 때 강사와 프로젝트 평가자는 PlaylistPro가 단순히 성능이 높은 분류기를 만든 프로젝트가 아니라, **리텐션 담당자가 제한된 자원으로 어떤 고객을 먼저 검토하고 어떤 유지 활동을 실험할지 결정하도록 돕는 의사결정 지원 프로젝트**임을 이해해야 한다.

## 최종 콘셉트

### 이탈을 예측하는 모델에서, 유지 활동의 우선순위를 정하는 의사결정 도구로

발표의 중심 질문은 다음과 같다.

> 모든 고객에게 같은 대응을 할 수 없다면, 누구를 먼저 검토하고 어떤 유지 활동 가설을 시험해야 하는가?

## 전체 Thesis

> PlaylistPro는 고객별 구독·이용·문의 데이터에서 낮은 청취 활동, Free 구독, 높은 문의 수준 등 이탈과 연관된 신호를 발견했다. 이 관찰을 전처리와 Feature 가설로 검증하고, 동일 Feature·동일 5-Fold 조건에서 8개 모델을 비교해 CatBoost를 최종 기술 후보로 선정했다. 최종적으로 모델 확률을 Threshold·Top-K 기반 검토 우선순위와 서비스 회복·재활성화·혜택 안내 등의 유지 활동 실험 후보로 연결했다.

## 발표에서 구분할 세 가지 결론

| 구분 | 발표에서 말할 수 있는 것 | 말하면 안 되는 것 |
| --- | --- | --- |
| 분석 결론 | 특정 행동·구독·문의 특성과 `churned` 사이의 관찰 연관성 | 해당 특성이 실제 이탈의 원인이라는 주장 |
| 모델 결론 | CatBoost가 현재 내부 OOF 근거에서 위험 고객 순위화 후보로 가장 안정적임 | 외부 고객에서도 동일 성능이 보장된다는 주장 |
| 비즈니스 제안 | 신호별 유지 활동을 A/B 테스트 후보로 제안하고 담당자가 선택할 수 있음 | 앱이 실제 캠페인을 실행했거나 이탈을 줄였다는 주장 |

## 프로젝트 중심 서사

1. 리텐션 담당자의 문제: 모든 고객에게 같은 비용을 쓸 수 없다.
2. 고객 이해: 어떤 행동과 고객군에서 이탈 라벨이 높게 관찰되는지 확인한다.
3. 행동 가설: 관찰 신호를 서비스 회복·이용 재활성화·혜택 안내 실험으로 변환한다.
4. 검증: 인사이트 기반 Feature 실험과 공정한 모델 비교로 우선순위 점수의 신뢰성을 확인한다.
5. 운영: Threshold와 Top-K로 검토 고객 수와 놓침 비용을 비교한다.
6. 제품: Streamlit에서 위험 신호, 행동 후보, 담당자 선택, 배치 우선순위를 하나의 흐름으로 제공한다.
7. 책임 있는 결론: 실제 유지 효과는 미래 라벨과 A/B 테스트로 검증한다.

## 본문 구성 원칙

- 본문 14장으로 구성한다.
- 프로젝트·인사이트·행동·운영 관련 슬라이드가 발표의 중심을 차지한다.
- 모델링은 Baseline, Feature 실험, 공정 비교, 최종 선정 논리를 설명하는 데 필요한 범위로 압축한다.
- 모든 슬라이드는 `질문 → 근거 → 의미 → 결정 → 다음 질문` 순서로 연결한다.
- 상세 Trial, 전체 Feature 목록, 패키지 버전은 질문 대응용 자료로 분리한다.

## 발표 핵심 비율

| 영역 | 본문 역할 | 슬라이드 |
| --- | --- | --- |
| 프로젝트 문제와 사용자 결정 | 왜 이 프로젝트가 필요한지 정의 | 1~2 |
| 데이터와 고객 인사이트 | 무엇을 관찰했고 어디까지 믿을 수 있는지 설명 | 3~4 |
| 행동 제안과 Feature 가설 | 인사이트가 실제 설계로 이어졌음을 설명 | 5~6 |
| 모델 검증 | 우선순위 점수가 어떻게 검증됐는지 설명 | 7~9 |
| 운영과 제품 활용 | 누구를 얼마나 관리하고 어떻게 행동할지 설명 | 10~12 |
| 책임 있는 해석과 결론 | 한계와 다음 검증을 가치로 연결 | 13~14 |

## 제외하거나 축소할 내용

- 20개 그래프 전체 나열
- 모델별 전체 하이퍼파라미터와 Trial 목록
- Accuracy 중심 설명
- Feature Importance를 원인처럼 설명하는 문장
- 검증되지 않은 30일 예측 기간
- 제공 test 75,000명을 Holdout으로 표현하는 문장
- 실제 LTV·ROI·Uplift가 확인됐다는 표현
- 과거 GradientBoosting 또는 LightGBM을 현재 최종 모델처럼 설명하는 자료
