# PlaylistPro 유지 전략 의사결정 계층 계획

## 목적

CatBoost의 역할을 고객 위험 순위 산출로 제한하고, 리텐션 담당자가 `누구에게 왜 어떤 행동을 검토하고 무엇으로 효과를 측정할지` 결정할 수 있는 별도의 설명 가능한 전략 계층을 제공한다.

## 의사결정 계약

| 구분 | 책임 |
|---|---|
| CatBoost | 제공된 `churned` 라벨을 기준으로 고객 위험 점수와 순위를 산출 |
| 전략 규칙 | 행동 가능한 관찰 신호를 고객 세그먼트와 행동 후보에 연결 |
| 리텐션 담당자 | 1순위·대안·직접 검토·보류 중 최종 선택 |
| 향후 캠페인 실험 | 행동별 실제 Uplift, 유지율, 비용 효과 검증 |

## 행동 전략 규칙

| 고객군 | 행동 가능 신호 | 1순위 행동 후보 | 검증 KPI |
|---|---|---|---|
| 서비스 회복 필요형 | 고객 문의 수준 High | 미해결 문의 확인 및 상담 우선 배정 | 문의 해결시간·반복 문의율·실험군 유지율 |
| 구독 휴지형 | 구독 일시정지 횟수 상위 구간 | 복귀 장애 요인 확인 및 구독 옵션 안내 | 재활성화율·재일시정지율 |
| 이용 저하형 | 주간 청취시간 하위 25% | 개인화 재활성화 콘텐츠 안내 실험 | 재방문율·주간 청취시간 변화 |
| 콘텐츠 탐색 피로형 | 스킵률 상위 25% | 추천 만족도 피드백 요청 실험 | 스킵률 변화·추천 클릭률 |
| Free 혜택 탐색형 | Free 구독 유형 | 유료 혜택 인지·체험 제안 실험 | 체험 참여율·유료 전환율 |
| 복합 고위험형 | 행동 가능 신호 2개 이상+높은 위험 점수 | 담당자 집중 검토 후 우선 장애 요인 해결 | 검토 완료율·접촉 성공률·실험군 유지율 |
| 일반 모니터링형 | 뚜렷한 행동 가능 신호 없음 | 현재 캠페인 제외·관찰 유지 | 위험 점수 이동·관측 이탈률 |

## 품질·안전 원칙

- Feature Importance를 이탈 원인이나 행동 효과로 해석하지 않는다.
- 행동 후보는 문의·이용·구독 신호만 사용한다. 나이·지역·고객 ID는 행동 근거에서 제외한다.
- 모든 제안은 `관찰 연관성 기반 가설·캠페인 효과 미검증`으로 표시한다.
- 단건 선택과 배치 큐 생성은 외부 CRM 상태를 바꾸지 않는다.
- 배치 큐의 기본 선택 상태는 `담당자 미검토`다.
- 비용·고객 가치·유지 전환율·순편익은 사용자 가정과 모델 점수로 계산한 민감도 분석이다.

## 구독 유형별 경제 가정

실제 가격·ARPU·마진·채널 비용 데이터가 없으므로 요구사항의 연간 LTV 120,000원을 Premium 기준점으로 사용하고 상대값을 추정한다. 앱에서 모두 수정할 수 있으며 실제 사업값이 아니다.

| 구독 유형 | 기본 접촉 채널 | 접촉 비용 가정 | 고객 가치 가정 | 추론 기준 |
|---|---|---:|---:|---|
| Free | 저비용 자동 메시지 | 1,000원 | 30,000원 | Premium 가치의 25%를 광고·전환 잠재가치 대용치로 가정 |
| Student | 자동화 혜택 안내 | 1,500원 | 72,000원 | Premium 가치의 60%를 학생 할인형 가치로 가정 |
| Premium | 개인화 디지털 접촉 | 3,000원 | 120,000원 | 기존 팀 가정 연간 LTV를 기준점으로 사용 |
| Family | 고관여 상담·혜택 안내 | 4,500원 | 180,000원 | Premium 가치의 150%를 다인 계정 가치 대용치로 가정 |

접촉 비용은 원칙적으로 실제 행동·채널 원가로 교체해야 한다. 현재는 구독 유형별 기본 채널을 함께 지정해 계획 초기값만 차등화한다.

## 배치 표 표시 원칙

- 전체 75,000명 전략 큐와 다운로드 CSV는 위험 점수 순서를 유지한다.
- 최상위 위험 고객은 실제로 복합 신호 구성이 유사해 운영 단계와 세그먼트가 반복될 수 있다.
- 화면 기본 표는 `운영 단계·세그먼트 대표 보기`로 각 조합을 교차 배치해 규칙의 다양성을 확인한다.
- `위험 점수 순`을 선택하면 실제 우선순위와 최상위 군의 동질성을 그대로 확인할 수 있다.

## 구현 순서와 완료 기준

1. 순수 Python 전략 규칙과 민감 Feature 제외 테스트
2. 단건 점수 결과에 세그먼트·복수 행동·실행 조건·KPI·담당자 선택 추가
3. 배치 CSV에 전략·근거·KPI·검토 상태 추가
4. 가정 기반 계획에 요금제별 설정·퍼널·순편익 곡선 복원
5. 6개 메뉴, 3개 고객 우선순위 탭, 입력 재추론, 다운로드, 반응형 화면 검증

완료 후에도 실제 캠페인 실행, 할인 적용, 고객 접촉, Uplift 확정은 범위 밖이다.
