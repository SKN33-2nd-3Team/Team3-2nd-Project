# 제출 전 사람의 확인이 필요한 항목

기술적으로 생성·검증할 수 없는 항목을 숨기지 않고 분리했습니다.

| 항목 | 현재 기록 | 필요한 결정 |
|---|---|---|
| 팀원별 최종 역할·회고 | README에 4명 역할·GitHub·회고 반영 | 팀원 최종 검토 |
| 세부 프로젝트 기간 | 공식 기간 2026-07-13~22 반영 | 완료 |
| 데이터 라이선스 | Kaggle Data 페이지의 MIT 표시 재확인, `data/LICENSE.md` 포함 | 기관별 추가 제출 제한이 있다면 별도 준수 |
| 사업 Threshold | 0.29 / 0.35 / 0.74 선택지 | 접촉 용량과 FN·FP 비용으로 선택 |
| 캠페인 행동 | 규칙 기반 실험 후보 | CRM·법무·운영 담당자 승인 |
| 효과·ROI | 미검증 | 실제 A/B 테스트와 미래 라벨 필요 |
| Google Drive 제출 | 로컬 ZIP 생성 | 사용자가 지정 폴더에 업로드 |
| GitHub 반영 | `docs/readme-template-alignment` 브랜치와 PR #20 사용 | 리뷰 후 병합 |

확인되지 않은 내용을 임의로 채우는 것보다 이 표를 최종 제출 담당자가 확인하는 것이 요구사항의 신뢰성에 부합합니다.
