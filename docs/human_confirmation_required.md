# 제출 전 사람의 확인이 필요한 항목

기술적으로 생성·검증할 수 없는 항목을 숨기지 않고 분리했습니다.

| 항목 | 현재 기록 | 필요한 결정 |
|---|---|---|
| 팀원별 최종 역할·회고 | Git 기여자만 확인 | 팀원이 실제 담당 역할과 회고 승인 |
| 세부 프로젝트 기간 | 2026-07-21~22 저장소 기록 | 공식 일정 확인 |
| 데이터 재배포 | Kaggle metadata 기록과 로컬 파일 존재 | Competition Rules·교육용 제출 범위 승인 |
| 사업 Threshold | 0.29 / 0.35 / 0.74 선택지 | 접촉 용량과 FN·FP 비용으로 선택 |
| 캠페인 행동 | 규칙 기반 실험 후보 | CRM·법무·운영 담당자 승인 |
| 효과·ROI | 미검증 | 실제 A/B 테스트와 미래 라벨 필요 |
| Google Drive 제출 | 로컬 ZIP 생성 | 사용자가 지정 폴더에 업로드 |
| GitHub 반영 | 로컬 브랜치만 사용 | 사용자가 승인할 때만 Push |

확인되지 않은 내용을 임의로 채우는 것보다 이 표를 최종 제출 담당자가 확인하는 것이 요구사항의 신뢰성에 부합합니다.
