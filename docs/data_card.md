### ⚠️ 공식 컬럼 설명과 실제 값의 불일치

대회 페이지의 컬럼 설명 중 **3개가 실제 데이터와 맞지 않는다.** 데이터가 문서를 따르지 않는다는 사실 자체가 합성 판정의 방증이며, 발표 시 컬럼 의미를 단정하지 않는 근거가 된다.

| 컬럼 | 대회 페이지 설명 | 실제 값 | 처리 |
|---|---|---|---|
| `num_subscription_pauses` | 일시정지 횟수 **(max 2)** | **0 ~ 4** (3·4회가 49,694건) | 실제 값 기준으로 사용. 문턱값 3회는 실측 |
| `signup_date` | 가입 **날짜(date)** | **음수 정수** −2,922 ~ −1 (기준일 대비 일수) | 날짜 파싱 불가. 파생 `signup_days_ago`만 사용 |
| `average_session_length` | 세션 길이 **(단위: 시간)** | 1.0 ~ 120.0 | 세션 120시간은 비현실적. **단위 미상**으로 처리한다. 현행 Pipeline 입력에는 포함되지만 중요도가 거의 없어 해석하지 않는다 |

## 합성 데이터 판정 근거

가이드는 "합성 데이터는 생성 규칙과 실제 적용 한계를 기록한다"고 요구한다. 관측된 증거는 다음과 같다.

1. **범주 균등성** — 요금제 4종이 각 25.0%, 결제수단 4종 각 25.0%, 상담등급 3종 각 33.3%로 편차 1% 미만
2. **피처 독립성** — 수치형 13개 전체 쌍에서 최대 |상관| = **0.007**. 실제 로그라면 청취시간과 재생곡 수는 강한 양의 상관이어야 한다
3. **논리 위반** — 고유곡 > 총재생곡 29.6%, 공유 > 생성 플레이리스트 24.6%
4. **정수 문턱값** — 이탈률이 5·10·40시간, skip 0.7, 일시정지 3회, 나이 25·35·61세에서만 계단식으로 꺾이고 구간 내부는 완전히 평평
5. **계수 복원** — 7개 신호를 구간 더미로 로지스틱 회귀 적합 시 계수가 거의 정확히 0.5 단위로 떨어짐

## 실제 적용 한계

1. **성능 수치를 실제 서비스 성능으로 발표할 수 없다.** Test PR-AUC 0.947은 심어진 생성 공식을 되찾은 값이며, 실무 이탈 예측 벤치마크는 통상 0.3~0.6대다.
2. **이론 상한이 존재한다.** Bernoulli 난수 때문에 달성 가능한 최대 정확도가 86.1%이고 현행 모델이 이미 84.8%다. 남은 1.3%p는 어떤 알고리즘으로도 회수할 수 없다.
3. **예측 시점이 정의되지 않았다.** 관측 기준일·해지일이 없어 "향후 30일 내 해지" 같은 시간 지평을 주장할 수 없다.
4. **2차 행동 분석 금지.** 논리 위반 레코드가 25~30%이므로 청취 패턴·소셜 그래프 해석에 사용해서는 안 된다.
5. **인과 해석 금지.** 모든 관계는 생성 규칙의 입력 변수를 되읽은 연관성이며, 캠페인 효과는 A/B 테스트로만 확정된다.
