# PlaylistPro 인사이트 중심 대시보드 최종 개선 프롬프트

## 역할

당신은 PlaylistPro 프로젝트의 Principal ML Engineer, Senior Data Analyst, Retention Product Lead, Senior UX Designer다. 목표는 화면을 화려하게 꾸미는 것이 아니라, CRM·리텐션 담당자가 **왜 이 고객을 먼저 검토해야 하는지, 모델을 왜 믿을 수 있는지, 어떤 운영 기준을 선택해야 하는지**를 빠르게 판단하게 만드는 것이다.

## 핵심 의사결정

> 제한된 리텐션 자원으로 누구를 먼저 검토하고, 이탈 고객 누락과 불필요한 접촉 사이의 균형을 어디에 둘 것인가?

모든 화면은 다음 이야기 순서를 유지한다.

1. 프로젝트 문제와 사용자의 결정
2. 데이터에서 관찰한 고객 행동 인사이트
3. 인사이트를 검증하기 위해 수행한 전처리·모델 실험
4. 동일 조건 비교와 정밀 검증을 통한 CatBoost 선정
5. Recall·Precision·FN·FP·대상 고객 수에 따른 운영 시나리오 선택
6. 선택한 기준으로 고객 우선순위 확인

## 반드시 지킬 사실 경계

- 타깃은 제공된 `churned` 관측 라벨이며 예측 기간은 정의되지 않았다.
- 모델 성능, Threshold, Top-K, Lift, Risk Decile은 저장된 5-Fold OOF 근거다. 독립 외부 라벨 Holdout 성능이라고 표현하지 않는다.
- 고객 행동 변수와 이탈의 관계는 연관성이다. 캠페인 효과, Uplift, ROI, 인과관계로 표현하지 않는다.
- 실제 CRM 발송, 할인 제공, 고객 접촉, 자동 조치는 수행하지 않는다.
- 모델 파일은 저장소 내부 경로와 SHA-256을 검증한 뒤 로드하며 화면에서 재학습하지 않는다.
- 운영 Threshold는 모델이 자동 확정하지 않고 사용자가 비용과 용량에 따라 선택한다.

## 화면 설계

### 1. 프로젝트 요약

- 고객·행동·결정이 보이는 강한 히어로 영역
- 학습 고객 수, 점수 산출 고객 수, 관측 이탈률, OOF PR-AUC 핵심 카드
- `인사이트 → 전처리 → 8개 모델 → 정밀 검증 → 운영 기준 → 고객 순위` 흐름
- Top 30% 포착률과 기본 운영 시나리오를 첫 화면에서 해석
- 할 수 있는 일과 할 수 없는 일을 분명하게 구분

### 2. 데이터·고객 인사이트

- 타깃 불균형, 결측·중복·ID 중첩 등 데이터 품질
- 청취시간, 스킵률, 구독 유형, 문의 수준 등 핵심 변수의 관측 이탈률 비교
- 각 인사이트마다 `관찰 → 활용 가설 → 한계`를 함께 제시
- CatBoost 전역 중요도와 EDA 연관성을 혼동하지 않도록 구분

### 3. 개선 실험

- Raw Logistic에서 log_numeric 채택까지의 전처리 성능 변화
- 채택 실험과 제외 실험을 모두 노출
- 8개 모델 동일 Feature·동일 Fold 비교
- Random Search와 상위 3개 Fine Tuning의 개선 폭 표시
- 각 조치에 대해 `문제 관찰 → 가설 → 변경 → 결과 → 결정` 기록

### 4. 모델 선정

- PR-AUC를 1차 기준으로 하되 Recall, Precision, F1, FN, FP를 동시에 비교
- CatBoost·LightGBM·XGBoost의 차이가 작다는 사실을 숨기지 않는다.
- Fine-tuned CV, OOF, 5개 Seed 안정성, Bootstrap CI, Calibration 근거를 분리해 보여준다.
- CatBoost는 단일 F1 최고 모델이 아니라, 최종 선택 규칙에서 가장 높은 CV PR-AUC와 안정성 때문에 선정됐음을 설명한다.

### 5. 운영 시나리오

- 재현율 우선, 균형형 F1, 정밀도 우선 중 사용자가 선택
- Threshold에 따른 대상 고객 수, Recall, Precision, F1, FN, FP 변화
- Top-K Capture·Lift와 Risk Decile로 용량 기반 우선순위 설명
- 사업 선택 질문을 화면에 남기되 자동 결정하지 않는다.

### 6. 고객 우선순위

- 원본 입력값을 사용자가 바꾸면 저장된 CatBoost로 위험 점수가 실제 재계산되어야 한다.
- 결과는 확률, 위험 구간, 선택 시나리오 기준 포함 여부로 표현한다.
- 주요 입력 맥락과 서비스 개선 가설을 제공하되 개인 단위 인과 설명으로 과장하지 않는다.
- 예측 모델과 분리된 투명한 전략 규칙으로 고객 세그먼트, 1순위·대안 행동, 실행 조건, 검증 KPI를 제시한다.
- 나이·지역·고객 ID는 행동 배정 근거에서 제외하고, 모든 행동은 담당자가 선택·직접 검토·보류할 수 있게 한다.
- 저장된 배치 점수에는 전략 세그먼트와 행동 후보를 결합해 다운로드한다. 기본 상태는 담당자 미검토다.
- 가정 기반 계획은 기본 채널별 캠페인 변동비와 구독 유형별 연간 매출 대용치 설정, 캠페인 퍼널, 연락 범위별 매출효과-비용 곡선을 제공한다. 이를 실제 LTV·기여이익·ROI로 표현하지 않는다.

## 디자인 원칙

- 기존의 네이비 사이드바, 오렌지 포인트, 그라데이션 히어로, 카드형 지표, 넉넉한 여백을 복원한다.
- 한 화면에는 하나의 핵심 질문을 두고, 제목 아래에 사용자가 무엇을 결정할지 한 문장으로 설명한다.
- 숫자만 나열하지 않고 바로 옆에 의미와 한계를 둔다.
- 색상은 선택·강조·위험 구분에만 사용하고 모델별 무지개색 남용을 피한다.
- 표는 발표 근거 확인용, 차트는 비교와 의사결정용으로 역할을 나눈다.
- 모든 사용자 노출 문구는 한국어로 작성하고 모델명·지표명만 필요한 경우 영문을 병기한다.

## 완료 조건

- 6개 메뉴가 오류 없이 열리고 핵심 차트가 저장 산출물과 일치한다.
- 단건 입력 변경 시 확률이 재계산된다.
- 단건 행동 후보와 배치 전략 큐가 동일한 규칙으로 생성되고 나이·지역 변경만으로 행동이 달라지지 않는다.
- 시나리오 변경 시 전 화면의 기준과 숫자가 일관되게 바뀐다.
- CatBoost 선정 이유와 LightGBM/XGBoost와의 차이가 사실대로 설명된다.
- 외부 Holdout, 미래 기간, Uplift, ROI에 대한 과장 문구가 없다.
- 모바일·좁은 화면에서도 카드와 입력 폼이 읽을 수 있다.
- 화면에서 모델 재학습이나 외부 시스템 실행을 하지 않는다.
